# Le-Ble-Sauvage
Notre restaurant "Le Blé Sauvage", est un restaurant située dans la ville de chartres. Le plat principal se nomme "Le colzoto des champs" il est composé: d'huile de colza, Champignons, Risotto et de Blé. En accompagnement, diverses boissons alcoolisées sont proposer, des euréliennes blonde, des Beauce &amp; Perche blonde, une IPA et des leffe ruby.
