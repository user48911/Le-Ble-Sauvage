# Le-Ble-Sauvage

Notre restaurant, **« Le Blé Sauvage »**, est situé dans la ville de Chartres. Notre plat principal se nomme **« Le Colzoto des champs »**. Il est composé d’huile de colza, de champignons, de risotto et de blé. En accompagnement, diverses boissons alcoolisées sont proposées : des Euréliennes blondes, des Beauce & Perche blondes, une IPA ainsi que des Leffe Ruby.
